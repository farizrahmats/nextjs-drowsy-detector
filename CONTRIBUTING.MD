# 🤝 Contributing Guide

Thank you for your interest in contributing to the **Drowsiness Detector App** 🎉  
We welcome all kinds of contributions: bug fixes, improvements, documentation, and new features.

## 📋 Before You Start

- Make sure you have **Node.js 18+**
- Use a modern browser (Chrome / Edge recommended)
- Familiarity with:
  - React & Next.js
  - TypeScript
  - Basic computer vision concepts (optional)
